# تطبيق «حياتي» لأندرويد

المستودع ده بيبني ملف التطبيق **MyLife.apk** لوحده على GitHub بأدوات جوجل الرسمية (Bubblewrap).

التطبيق بيفتح نفس موقع «حياتي» (`https://bodax7.github.io/My-life-V4/`) بملء الشاشة وبكل مزاياه: الإشعارات والبصمة والإملاء بالصوت والمشاركة من التطبيقات التانية والكاميرا والجدول. وأي تحديث بترفعه على الموقع بيوصل للتطبيق لوحده، **من غير ما تبني ملف جديد**.

## تنزيل آخر نسخة
من الموبايل افتح:
`https://github.com/bodax7/mylife-android/releases/latest/download/MyLife.apk`
(لو سميت المستودع اسم تاني غيّر `mylife-android` في الرابط.)

لو أندرويد سأل، اسمح بالتثبيت من المتصفح. النسخة الجديدة بتتثبت فوق القديمة وبياناتك زي ما هي.

## إمتى تحتاج تبني نسخة جديدة؟
بس لو عايز تغيّر حاجة في «غلاف» أندرويد نفسه: اسم التطبيق، أو الاسم تحت الأيقونة، أو ألوان شريط الحالة، أو اتجاه الشاشة، أو رقم الإصدار، أو الأيقونة.

**إزاي:** افتح `twa-config.json` هنا على GitHub ← أيقونة القلم ✏️ ← عدّل القيمة ← **Commit changes**.
البناء بيبدأ لوحده (تقدر تتابعه من تبويب **Actions**) وبعد حوالي 5–7 دقايق النسخة الجديدة بتظهر في **Releases**.

الأيقونة بتتاخد من موقعك (`icon-512.png` و`icon-maskable-512.png`)، فلو غيرتها هناك اضغط **Actions ← بناء تطبيق أندرويد ← Run workflow** عشان النسخة الجاية تاخدها.

## الملفات
| الملف | وظيفته |
|---|---|
| `twa-config.json` | الإعدادات اللي تقدر تعدلها |
| `generate.mjs` | بيجهز مشروع أندرويد من الإعدادات وملف manifest بتاع موقعك |
| `package.json` و `package-lock.json` | نسخة Bubblewrap المستخدمة (ثابتة) |
| `android.keystore` | مفتاح توقيع التطبيق — مقفول بكلمة سر محفوظة في **Secrets** باسم `KEYSTORE_PASSWORD` |
| `.github/workflows/build-apk.yml` | خطوات البناء والتوقيع والنشر |

⚠️ **متمسحش `android.keystore` ومتغيرش `معرف_التطبيق`** — من غيرهم النسخ الجديدة مش هتتثبت فوق القديمة.

## لو البناء فشل
افتح **Actions** ← آخر تشغيل باللون الأحمر ← الخطوة الحمرا. الرسالة بتقول السبب بالعربي (زي كلمة سر ناقصة أو غلط في الإعدادات). لو الرسالة مش واضحة ابعتها لـ Claude.

## شريط العنوان فوق التطبيق
لو ظهر شريط صغير فيه عنوان الموقع فوق التطبيق، يبقى ملف `assetlinks.json` لسه مش موجود على `https://bodax7.github.io/.well-known/assetlinks.json` (مستودع `bodax7.github.io`). بعد ما يترفع، اقفل التطبيق خالص وافتحه تاني (ممكن ياخد لحد يوم).
